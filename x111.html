لوحة تحكم فحص البروتوكولات (Security Audit)

هذه الصفحة مخصصة لفحص كيف يتعامل نظام التشغيل مع طلبات البروتوكول من المتصفح.

1. أدوات التحكم والعمل عن بُعد (Remote Admin)

fleetdeck:// - FleetDeck Commander Launcher
GovReach:// - Goverlan Reach Console
zocom:// - 01Launcher (IIT)

2. أدوات النظام والتشخيص (Windows System)

ms-msdt:// - Microsoft Support Diagnostic Tool
ms-controlcenter:// - Windows Control Center
ms-mmsys:// - Sound Settings (Rundll32)
WdMam:// - Security Health Host

3. الاتصالات والشبكات (Terminal & Network)

telnet:// - Telnet Protocol Handler
rlogin:// - Rlogin Handler
LDAP:// - Windows Mail (WAB)

4. المراسلة والتصفح (Communication)

tg:// - Telegram Desktop
mailto:// - Thunderbird Mail
microsoft-edge:// - MS Edge

5. البحث وإدارة الملفات (Shell)

search-ms:// - Windows Search
calculator:// - Win32 Calc
